# 大岚文旅数据分析系统

一个轻量级全栈 Web 系统，用于维护大岚镇民宿、景区、新业态、农家乐、活动和日参考数据，并按月进行经营数据分析。

## 当前功能

- 基础维护：维护民宿、景区、新业态、农家乐基础资料。
- 账号角色：管理员可维护全镇数据；民宿、景区、新业态、农家乐账号只能维护自己的资料和月度数据。
- 运维录入：按月选择具体对象录入住率、入住人数、游客量、营收等，不同类型显示不同字段。
- 活动维护：活动由管理员统一维护，可记录活动日期、活动名称、游客量、营收和备注。
- 日参考参数：管理员录入某一天的车流量、游客量、停车压力等，用作数据分析参考。
- 数据分析：查看本月数据、同比环比、月度趋势、排行、异常提醒、活动与经营主体联动关系。
- 数据导出：前端一键导出 JSON 数据。

## 本地运行

```powershell
node server.js
```

如果当前电脑的 `node` 不在 PATH，可使用 Codex 自带 Node：

```powershell
& 'C:\Users\caigen\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' server.js
```

启动后访问：

```text
http://localhost:3000
```

## 数据库

系统使用 SQLite 保存正式数据，运行后会自动创建：

```text
data/dalan-tourism.db
```

`data/` 目录属于运行时数据，默认不提交到 GitHub。正式部署时请单独备份数据库文件。

## 默认账号

系统会在首次运行时生成基础账号，具体以服务器数据库中的账号维护页面为准。新增经营主体账号时，默认密码为：

```text
dl123
```

## 部署建议

- 起步阶段：腾讯云轻量服务器 + Node.js + SQLite。
- 正式使用：增加 Nginx、HTTPS、域名和定期数据库备份。
- 后续扩展：可升级 PostgreSQL / MySQL，并增加 Excel 导入、报表导出和地图视图。
